# beauty-salon-config
Дипломная работа курса «Разработчик 1С: расширенный» (Яндекс Практикум). Нетиповая конфигурация: БСП, оперативный и бухгалтерский учёт, мобильное приложение, интеграция, загрузка прайс-листа из Excel.

# Конфигурация «Салон красоты» + мобильное приложение

Дипломный проект, разработанный с нуля на платформе 1С:Предприятие 8.3. 

---

## 📋 Архитектура проекта

### Этап 1 — MVP (минимально жизнеспособный продукт) и оперативный учёт
- Внедрены обязательные подсистемы БСП с постановкой на поддержку поставщика и адаптацией кода
- Дополнительно подключены подсистемы БСП: Организации, Печать, Дополнительные отчёты и обработки
- Разработан собственный стиль оформления, загружены логотип и заставка
- Созданы подсистемы и группы команд для настройки интерфейса
- Разработан каркас метаданных: перечисления, справочники, документы, регистры накопления и сведений
- Реализованы оперативные отчёты: Товары на складах, Продажи, Финансовый результат, Движение наличных денег
- Настроен контроль отрицательных остатков с выводом сообщения пользователю через БСП

### Этап 2 — Расширение и интеграция
- Разработана подсистема Бухгалтерский учёт: план видов характеристик, план счетов, регистр бухгалтерии
- Настроены автоматические проводки по всем документам-регистраторам с корреспонденцией счетов
- Создан Журнал хозяйственных операций и отчёт Оборотно-сальдовая ведомость по счёту
- Реализована внешняя печатная форма «Товарная накладная» через механизм БСП
- Разработана загрузка прайс-листа из Excel в регистр Цены номенклатуры
- Создана мобильная конфигурация для записи клиентов с авторизацией и обменом данными

## 📂 Состав конфигурации

### Подсистемы
Продажи | Покупки | Управление персоналом | Денежные средства | Справочники | Сервис и настройки | Бухгалтерский учёт

### Перечисления
Типы организаций, Типы номенклатуры, Пол физического лица, Типы контрагентов, Виды цены, Виды операций поступления/расхода денег

### Справочники
Номенклатура (иерархический) | Сотрудники | Должности | Контрагенты (иерархический) | Договоры (подчинён Контрагентам) | Организации | Источники информации | Пользователи (из БСП) | Статьи затрат | Кассы | Склады

### Документы
| Документ | Особенности |
|---|---|
| **Поступление товаров и услуг** | Две ТЧ (Товары, Услуги), движения по всем регистрам |
| **Предварительная запись** | Основание для Реализации |
| **Реализация** | Вводится на основании Предварительной записи, печатная форма «Реализация» |
| **Приходный кассовый ордер** | Ввод на основании Реализации и Поступления, автозаполнение по виду операции |
| **Расходный кассовый ордер** | Ввод на основании, автозаполнение реквизитов |

### Регистры накопления
| Регистр | Тип | Назначение |
|---|---|---|
| Товары на складах | Остатки | Движения ТМЦ, контроль отрицательных остатков, себестоимость по средней |
| Заказы клиентов | Остатки | Контроль исполнения заказов |
| Продажи | Обороты | Выручка по товарам и услугам (со сворачиванием строк) |
| Учёт затрат | Обороты | Себестоимость реализации, затраты по услугам |
| Денежные средства | Остатки | Движение наличных в кассах |

### Регистры сведений
- **Цены номенклатуры** (периодический, в пределах дня) — с формой списка и загрузкой из Excel

### Регистр бухгалтерии
- **Хозрасчетный** (Журнал бухгалтерских проводок) — суммовой учёт, корреспонденция счетов

### Отчёты
| Отчёт | Источник данных | Особенности |
|---|---|---|
| Товары на складах | Регистр «Товары на складах» | Остатки и обороты, макет «Античный», красный цвет для отрицательных |
| Продажи | Регистр «Продажи» | Только услуги, группировка по мастеру/клиенту/услуге, сортировка по убыванию |
| Финансовый результат | Продажи + Учёт затрат | Доходы − Расходы, прибыль зелёным / убыток красным |
| Движение наличных денег | Регистр «Денежные средства» | Остатки и обороты по кассам |
| Оборотно-сальдовая ведомость | Регистр «Хозрасчетный» | По счету и субконто, стандартный период |

### Функциональная опция
- **Использовать склады** — управляет видимостью складских объектов

## 🛠 Ключевые технологии и навыки
- **БСП (Библиотека стандартных подсистем):** внедрение обязательных подсистем, адаптация кода, использование механизмов печати и доп. отчётов
- **Бухгалтерский учёт:** план счетов, план видов характеристик, регистр бухгалтерии, корреспонденция счетов, автопроводки
- **Интеграция:** мобильная платформа 1С, обмен данными
- **Внешние печатные формы** через механизм БСП
- **Загрузка данных из Excel**
- **Контроль отрицательных остатков** с сообщением пользователю (метод `СообщитьПользователю` из БСП)
- **Расчёт себестоимости по средней скользящей**
- **Ввод на основании** с автозаполнением реквизитов
- **Условное оформление отчётов** (цветовые индикаторы)
